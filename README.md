# CampusNotes

A simple Python-based note-taking application.

## Features
- Add notes
- Save notes in a text file
- View saved notes

## Technology
- Python 3

## Author
Aman Lal Singh
Updated from second cloned repository.
## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the command:

   python main.py

## Usage

- Select 1 to add a note.
- Select 2 to view saved notes.
- Select 3 to exit the application.

## Validation

Empty notes are not allowed.
